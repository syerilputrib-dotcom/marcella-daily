☁️ Koneksi Database Supabase

Agar siapa saja bisa mengedit & data tersimpan permanen di semua HP/PC secara real-time:
1. Buat project gratis di supabase.com
2. Buka SQL Editor lalu jalankan perintah ini: 

create table if not exists ella_daily (
  id text primary key,
  payload jsonb not null,
  updated_at timestamptz default now()
);
alter table ella_daily disable row level security;
